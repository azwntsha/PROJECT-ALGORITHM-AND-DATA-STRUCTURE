# Project Description

The Food Court Table Management System is a web-based application developed to help customers and staff efficiently manage table availability in a food court. The system allows users to search for available tables, perform customer check-in and check-out, and monitor table occupancy in real time.

To improve performance, the system implements two data structures:

- **Hash Table Algorithm** for fast table lookup and updates using the table ID.
- **Array List Algorithm** for storing, filtering, and displaying tables history.

This combination provides an efficient and user-friendly solution for managing food court seating.

# Features

- Search table by Table ID
- Customer Check In
- Customer Check Out
- View Table Status
- Check In/Check Out History
- Fast table lookup using Hash Table
- Dynamic table filtering using Array List

# Data Structures Used

1. Hash Table Algorithm

Used for:
- Searching tables
- Updating table status
- Retrieving table information

Average Time Complexity:
- Search: **O(1)**
- Update: **O(1)**

2. Array List Algorithm

Used for:
- Storing all tables
- Displaying table information
- Filtering available tables
- Storing history records

Average Time Complexity:
- Filtering: **O(n)**
- Displaying: **O(n)**
